Section I: Bezier Curves and Surfaces

Part 1: Bezier Curves with 1D de Casteljau Subdivision

A Bézier curve is a parametric curve \(x(t)\), \(t \in [0, 1]\) that is defined by various control points. It passes through the first and last control points. The other points are called handles, and they are basically directional control lines that help direct the path of the curve. de Casteljau’s algorithm is a method to construct a Bezier curve. It evaluates \(x(t)\) by repeated linear interpolation on the points that define the curve. Each step replaces every adjacent pair with \((1 - t)\, b_i + t\, b_{i+1}\), which is basically the linear interpolation of every pair of neighboring points,so each level has one fewer point. The last remaining point is \(x(t)\) (a point along the curve). A Bézier curve is the path traced by the last point of de Casteljau as \(t\) runs from 0 to 1. One run of the algorithm gives one point. The curve is all of those points.

In terms of the implementation, the BezierCurve::evaluateStep function is responsible for performing single step of the algorithm. This means that we start with N control points, perform a step, and are left with N-1 points (that is what makes up a single step). The implementation performs N-1 linear interpolations to produce N-1 new points, and then returns those as a vector. The rest of the code calls this function once per level, and so pressing E will show one row of the de Casteljau pyramid at a time.
